# Анкета для записи на курс — сайт-опрос с интеграцией в Telegram

SPA-анкета (Next.js 14, App Router) с плавными переходами между шагами,
телефонным инпутом с выбором страны, сохранением заявок в базу данных
и уведомлениями в Telegram-группу. Готова к деплою на Vercel.

---

## 1. Технологии и одно важное архитектурное решение

- **Next.js 14** (App Router) — фронтенд + серверные API-роуты в одном проекте.
- **Turso (libSQL)** — база данных вместо обычного файла SQLite.

> **Почему не просто SQLite-файл, как было в ТЗ.**
> Vercel — serverless-платформа: файловая система там пересоздаётся при
> каждом запросе и **не сохраняет** изменения между вызовами функций.
> Обычный файл `database.sqlite` на Vercel будет обнуляться, и все анкеты
> потеряются. Turso — это тот же самый SQLite «под капотом» (тот же
> синтаксис, тот же движок), но база живёт в облаке и доступна из
> serverless-функций. Для вас это ничего не меняет по сложности —
> настройка занимает 2 минуты (см. ниже), а работать с ним из кода можно
> так же просто, как с обычным SQLite.
> Если вы соберётесь разворачивать проект не на Vercel, а на собственном
> сервере (VPS) — можно вернуться к обычному файлу SQLite, для этого
> нужно будет заменить `lib/db.js` на `better-sqlite3`.

```
onboarding-quiz/
├── app/

│   └── ui/

│       ├── ProgressTrail.jsx    # прогресс-бар
│       └── SelectableCard.jsx   # карточки выбора вариантов
├── config/
│   ├── site.config.js           # ⚙️ имя, тексты, ссылка на канал, подарок
│   └── questions.config.js      # ⚙️ вопросы анкеты и варианты ответов
├── lib/
│   ├── countries.js             # список стран для phone-инпута
│   ├── db.js                    # работа с базой данных (Turso)
│   ├── telegram.js              # формирование и отправка уведомления
│   └── validation.js            # серверная валидация (никогда не доверяем клиенту)

├── .env.example                 # шаблон переменных окружения
└── README.md
```

## 4. Установка и запуск локально

```bash
# 1. Установить зависимости
npm install

# 2. Скопировать шаблон переменных окружения
cp .env.example .env

# 3. Заполнить .env (см. раздел 5 и 6 ниже)

# 4. (необязательно) проверить подключение к базе и создать таблицу
npm run db:init

# 5. Запустить проект
npm run dev
```

Сайт откроется на http://localhost:3000

## 5. Настройка Telegram-бота

1. Напишите **@BotFather** в Telegram.
2. Отправьте `/newbot`, придумайте имя и username бота.
3. BotFather выдаст токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Вставьте его в `.env`:
   ```
   TELEGRAM_BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
4. Создайте Telegram-группу, куда будут приходить заявки.
5. Добавьте вашего бота в эту группу (как обычного участника).
6. Отправьте в группу любое сообщение (например «привет»).
7. Откройте в браузере:
   ```
   https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates
   ```
8. В ответе найдите `"chat":{"id": -100XXXXXXXXXX, ...}` — это Chat ID
   группы (обычно отрицательное число). Вставьте его в `.env`:
   ```
   TELEGRAM_CHAT_ID=-100XXXXXXXXXX
   ```

Готово — при заполнении анкеты бот пришлёт в группу сообщение со всеми
ответами пользователя.

## 6. Настройка базы данных (Turso)

```bash
# 1. Установить Turso CLI
curl -sSfL https://get.tur.so/install.sh | bash

# 2. Зарегистрироваться / войти
turso auth signup

# 3. Создать базу
turso db create ainur-quiz

# 4. Получить URL базы
turso db show ainur-quiz --url
# → вставьте результат в .env как TURSO_DATABASE_URL

# 5. Создать токен доступа
turso db tokens create ainur-quiz
# → вставьте результат в .env как TURSO_AUTH_TOKEN
```

Таблица `submissions` создаётся автоматически при первой отправке анкеты
(можно также создать её заранее командой `npm run db:init`).

## 7. Деплой на Vercel

1. Загрузите проект в GitHub-репозиторий.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и
   выберите репозиторий.
3. В настройках проекта откройте **Environment Variables** и добавьте
   те же переменные, что в вашем `.env`:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `TURSO_DATABASE_URL`
   - `TURSO_AUTH_TOKEN`
   - `APP_SECRET`
4. Нажмите **Deploy**.

После первого деплоя сайт будет доступен по адресу вида
`https://ваш-проект.vercel.app` — эту ссылку можно будет привязать к
собственному домену в настройках Vercel (**Settings → Domains**).

## 8. Куда вставить ссылку на подарок / PDF

Откройте `config/site.config.js`, блок `gift`:

```js
gift: {
  title: "PDF-гайд «...»",       // название подарка — можно менять
  fileUrl: "https://example.com/replace-with-real-gift-link.pdf", // ← сюда ссылку на файл
},
```

Файл можно загрузить, например, в Vercel Blob, на Google Drive
(с открытым доступом «по ссылке») или на любой другой хостинг файлов —
и вставить прямую ссылку сюда.

## 9. Просмотр собранных анкет

Для MVP отдельной админ-панели нет — каждая новая анкета сразу приходит
уведомлением в вашу Telegram-группу, а также сохраняется в базе Turso.
Посмотреть все анкеты можно через Turso CLI:

```bash
turso db shell ainur-quiz
SELECT * FROM submissions ORDER BY created_at DESC;
```

Функция `lib/db.js → listSubmissions()` уже готова, если вы позже
захотите добавить простую страницу-админку или подключить CRM.

## 10. Безопасность и защита от спама

- Telegram Bot Token и данные БД используются только на сервере
  (в API-роуте), никогда не попадают в код, который выполняется в браузере.
- Все поля проверяются заново на сервере (`lib/validation.js`) — даже
  если кто-то обойдёт проверку на фронтенде, невалидные данные не
  сохранятся.
- Простой anti-spam: не больше 3 анкет с одного IP за 10 минут
  (`app/api/submit/route.js`), плюс honeypot-поле `website`, невидимое
  для обычных пользователей, но заполняемое ботами.
